# 7DOF 算法一致性核对

## 结论

**全部一致，沿用原工况。** 对照方向为 Unity → `7DOF_masscenter_real_constraint`。4,001 个采样帧的模式逐点一致，七轴角最大差 `2.02×10⁻¹² rad`。本轮对机械臂部分仅清理可见错误文案，保留基座、连杆、夹爪、捕获座及其映射。原交付目录零改动。实装几何适配继续使用上一轮验证过的参考装配。

量测采用 Unity Play Mode 的生产 `SpatialDynamicsAdapter`、同一演示场景、原配置和生产对日函数。单步调用每个 20 ms 样本，避免普通 TCP 遥测间隔漏掉中间帧。独立运行交付的原始 Release exe，另用新分发包的真实 Windows Player 跑完整 TCP 回归。初次在 Edit Mode 测量时，Prefab Transform 没有按运行时方式重挂，量到了未标定网格；已排除该数据，以下均使用通过检查的 Play Mode 结果。

## 旧版为什么会画出断续的机械臂

7DOF 求解器给出的是每个关节轴心和工具参考点的位置、方向。FBX 里的每段实体也有自己的原点，实际接合端面可能离原点有一段距离。旧版把整船缩放后，直接把模型节点套到原生关节坐标，且部分长杆归到了相邻的错误臂段。这样即使两端的计算坐标连续，Unity 画出来的杆件端面仍可能对不到下一个关节，转动后尤其明显。旧版基座和目标捕获轴也有各自的安装基准差。详细旧版证据见 [断续与附着归因](机械臂断续与附着_归因报告.md)。

现在用参考 FBX 的实际端面登记每段杆件，按正确的近端和远端绑定，同时登记基座、夹爪和目标捕获座。柔性段的末端挠曲仍来自原生输出。原生抓捕是带残差收敛的约束，捕获后的第一个 20 ms 样本仍有约 14.93 mm 的工具到捕获点残差。旧版悬空杆件与这段真实计算残差是两种现象。

## 穿模核查

使用实际显示网格的定向包围盒，以 15 轴分离轴检测。逐帧检查七段、己方两翼、八个最大舱体网格，以及两器各八个最大舱体网格之间的干涉。10 个重点帧另将两器全部 1,248×1,248 个活动舱体网格对逐一比较，排除太阳翼。相邻连杆接头允许其包围盒正常重叠。盒的相交深度描述示意外形的包络，不能作为实体表面穿透深度或飞行净空数据。

- **己方太阳翼与机械臂**。初态至 **21.48 s** 检出 J7 与己方太阳翼 1 子件 `SJN101S-22-A_ZK_BODY` 包围盒重叠，覆盖接近、抓捕和早期搬运。抓捕后峰值 **8.98 s，约 53.2 mm**。在所检帧中，连杆与己方八个主要舱体件未检出盒重叠。

- **43.60 s 两器**。两器八个主要舱体件的包围盒分离。全舱体细件扫描检出 **252 对**盒重叠，最大一对约 **0.191 m**。完整两个件号见 `geometry-summary.json` 的 `selected_43_60_top`。其它九个重点帧全舱体细件扫描未检出跨器盒重叠，包括二次碰撞后 52.28 s、锁紧 58.02 s、释放后 64.02 s。对接参考点在 **43.60 s** 相距 **0.476690 m**，质心距 **2.263317 m**。在己方本体 **Unity** 坐标，来访器相对位置为 `(2.109459, 0.673211, 0.468588)` m，相对四元数 `(−0.108226, −0.092838, 0.168979, 0.975251)`（xyzw）。工具到抓捕点 **1.15 nm**，轴向间隙 **−0.297609 m**，此时仍为抓捕搬运，尚未触发端口事件。

## 原算法疑点

原始工况的接触模型以工具/抓捕点、对接参考点及其局部容差作为接触对，示意 FBX 的所有部件均为展示资产。这是模型边界。两组原始自检、完整原始重跑及 Unity 对照没有发现原始算法参数自相矛盾。各项相同物理量的对照误差见 JSON。

## 锥面与文案

四棱锥对应矩形像面或矩形角域的四个角点。以光轴为中心的等角轮廓适合圆锥表示，水平和垂直张角各自定义时可用椭圆截面。按本轮要求，显示使用 64 段透明开口锥面，`rH = L·tan(H/2)`，`rV = L·tan(V/2)`。两半轴相等即为圆。缺省 CRDS 为 32°×32°，五路 TV 均为 55°×55°。32°×32° 与 55°×32° 的 18 m 测试分别得到 `5.161417×5.161417 m` 和 `9.370207×5.161417 m` 半轴。光心、光轴和长度沿用旧显示参数。锥面保留旧边界的水平、垂直半角，矩形对角角域与椭圆环不同。相机投影、视场入场计算、遮挡判定与预警继续使用各自原判定。正式包「显示射线」勾选、筛选和关闭均经 Qt 实测。
