# 工程决定

## 2026-11-27 · 方案 A 定版

- 按用户确认保留空间站一侧的 CRDS 和两路对接电视。腕部两路保留抓捕端挂点，用固定相机角度和支架偏移观察来访器捕获座。肘部采用原生 J5 的固定工作区机位。取样、锥面和镜头沿用 Qt JSON 配置，实体沿用现有参考模型。[安装与验收](敏感器位姿核对.md)
- 原用户 JSON 继续通过既有按机位 ID 合并流程读取。仅当位置、旋转、靶标与采样尺寸仍等于旧默认组合时，迁移到新增的捕获座配置。完整旧参数副本通过实机测试。

## 2026-11-27 · 第四轮

- Qt 测试滑块以收到的七轴读数为起点，初态或终态显式启用。滑块与数字框共用 0.1° 刻度。Unity 总览只画参考网格副本，活动物理结构继续由 Adapter 驱动。播放、暂停和旧轮次消息由 Unity 进行第二层门控。
- 太阳显示是本地配置 `showSunVector`，默认关闭，保存参数时持久化。总览日盘、向日箭头和标签共用一个绑定，光照方向与地影继续由同一运行时更新。「显示射线」控制既有传感器锥面。
- 保留方案 A 作为现有验收配置。按 §1 记录双器安装冲突与可选口径。按 §4 把合同差距和影响提交书面核对。详见 [六路位姿](敏感器位姿核对.md) 和 [任务书审计](任务书符合性核对.md)。

## 2026-11-27 · 算法核对、锥面和文案

- 以原始 `7DOF_masscenter_real_constraint` 为只读数值基准。按「全部一致」分支保留动力学、参考装配标定和预测算法。两处疑似干涉均使用运行时示意网格的定向包围盒核查，测得的包络重叠与工况状态、端口及抓捕残差一同记录。
- 继续以既有光心、光轴和量程显示视场。等水平和垂直 FOV 用圆锥，异 FOV 用椭圆锥。64 段开口曲面和原有透明度配合总览观察，现有相机投影、矩形角域、采样点遮挡和未来预警判据继续使用原值。控件名为「显示射线」。
- 删除来访器展示标签的「同组」以及诊断里可见的「组内」。保留三处内部 Transform 节点名称的原语义。详细命中及处理依据见 [算法一致性核对](7DOF_算法一致性核对.md#锥面与文案)。

## 历史决定 · 装配与 80 秒预警

- 以组内七轴 `bq` 分支的实体为准。在 Unity 编辑器以实际 FBX 网格的端部切片测定接合面中心。组内网格依次为关节 1、2、5、3、4、6、7 实体。两根长杆分别从 CAD 节点 3 和 4 伸向下一关节，关节 5 实体是短执行器。第七段远端以参考夹爪 basePlate 登记。每段对应一个原生近端关节和一个下游原生关节或工具端。保留截面和材料，沿段轴静态换算 CAD 基准长度。柔性第 4、5 段用原生近端姿态和远端挠曲后的坐标显示端到端变形。
- 两器位置采用原生质心。舱体端口与抓捕座分别装配，原生端口和捕获点之间的距离为约 1.60 m，参考模型仅约 0.38 m。组内基座和轴使用舱体碰撞网格的安装交点，基座随己方刚性运动，目标轴随来访器刚性运动。夹爪采用参考装配控制器 `basePlate` 的位置与光轴基准。1.370 m 基座跨距与 0.334 m 捕获座跨距用于组内几何工程验证，需真实装配资料才能作实物验收。
- 碰撞预测从原生 `Session` 克隆，保留接触、约束和事件时钟，后台以 1 ms 固定步长推进，20 ms 取样直至 80 s。暂停在原生样本边界冻结副本并停止遮挡读取。复位、传感器配置、轨道参数和手动帆板参数变化使旧结果作废。
- 预测使用同一采样点和遮挡阈值。离屏碰撞体按各个分支的固定相对位置建独立碰撞树，每次将求交射线变换到各分支的局部坐标。自动帆板按预测起点的太阳方向与原生本体姿态运行现有对日算法。Qt 的太阳轨道时钟独立于动力学时钟，当前预警只覆盖两器和机构的动态遮挡。预测列展示第一个遮挡区间、计算进度或全段无挡，TCP 另带累计时长和峰值比例。
- 「显示射线」保留原文案和选项，改为透明度 6.5% 的开口四棱锥面。顶点和四个端点复用既有光心、水平/垂直 FOV 与绘制量程。材质仅显示在总览。
