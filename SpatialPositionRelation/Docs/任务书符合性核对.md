# 空间位置关系计算模块任务书符合性核对

核对对象为 Windows 定版 `20261127_220036_022`，历史原始取证来自候选 `20261127_173257_711`。正式安装为 `20261127_163137_130`。两者共用原生动力学与现有参考装配。本报告采用「符合 / 不符合 / 存疑」，每行注明验证边界。合同差距按原目标 §4 提交评议。

**核对依据**为 [五院项目任务书](../../归档/doc/五院项目_任务书.docx)、[Goal.txt](../../归档/文档/Goal.txt)、[模块需求分析报告](../../归档/doc/通用联合仿真系统需求分析报告_空间位置关系计算模块.docx) 和 [设计报告 V4.3](../../归档/doc/在轨交会对接任务的通用联合仿真系统_设计方案报告_V4.3.docx)。表中 P 为 `word/document.xml` 的正文 `w:p` 序号，从 1 起计，包含目录、空段及表格单元格里的段落。§5.1.2 对应 P89–97，§5.2(2) 对应 P115。以任务书条款原文为判定依据，Goal 和后续确认用来说明算法验证范围。

核对记录保存了任务书原文件的 SHA-256，以及直接涉及该模块的 10 个原文段落到 M 行的映射。P94 对应 M03a。M03b 引用 Goal (3) 补充安装和界面要求。见 [协议与条款审计原始数据](../../归档/验收证据/第四轮_测试关节与任务书/spr1-and-contract-audit.json)。

定版采用用户确认的方案 A。安装清单、三路捕获座工况和本轮复验见 [六路敏感器安装报告](敏感器位姿核对.md) · [定版试验日志](../../归档/验收证据/第四轮_方案A位姿/player-final.log)。

## 接口边界和时序

- 输入包括双器的质心、姿态、端口、机械臂关节和抓捕点，来源为本地 Adapter 的原生会话。Qt 经 SPR/1 提供轨道六要素、起始历元、时间倍率以及敏感器启用状态、安装位姿、目标、水平和垂直 FOV 及告警配置。Unity 读取装配体几何和遮挡身份。参见 [协议](TCP_PROTOCOL.md) · [配置](../../Spatial_Qt/SpatialPositionRelation/config/default_config.json) · [原生 Adapter](../Assets/Scripts/SpatialDynamicsAdapter.cs)。
- 输出包括两器相对距离、对接状态、端口和工具残差、七轴角、太阳向量、受光角度、直射受光比例、地影、目标入场与可见点数、面积比例、遮挡部件、预警与建议。实时遥测还提供未来首段遮挡、累计遮挡/出场时间、峰值遮挡点比例和预测进度。Qt 显示、逐路保存、截取画面以及录制 PNG 序列。参见 [SPR/1 字段](../Assets/Scripts/SpatialProtocol.cs) · [回放遥测](../../归档/验收证据/第四轮_测试关节与任务书/qt-ui/80秒候选原始遥测.jsonl)。
- §5.1.2 与 §5.2(2) 描述实时性及准确性，数值误差上限、统一时标、最长延迟、最小目标判定尺寸以及帧率待合同细则明确。当前原生固定 1 ms 积分、20 ms 采样，Qt 消费约 0.2 s 一包，地心轨道与太阳使用独立历元和时间倍率。默认回放得到连续 370 个包。与原始 CSV 比对，七轴最大差 `1.91×10⁻¹² rad`，端口和工具位置最大差 `0.122 μm`。见 [Qt 原始回放与落盘检查](../../归档/验收证据/第四轮_测试关节与任务书/qt-ui/界面回放与落盘核对.json)。预测首次在工况 21.88 s 覆盖到 80.00 s，该包的 CRDS 首次预警为 44.46–80.00 s。参见 [原生步进](../Native7Dof/Spr7Api.cpp#L10) · [上报定时](../Assets/Scripts/SpatialRuntime.cs#L198) · [预测实测](../../归档/验收证据/第四轮_测试关节与任务书/qt-ui/预测至工况结束-同帧TCP.json)。

- 两版实机 TCP 覆盖 7 类既有 SPR/1 报文，字段路径一致。新增 `presentation` 用于测试机械臂与太阳显隐。本地原生 ABI 和导出一致。两轮共 12 个两版共用采样点的动力学和七轴角输出一致。见 [协议与条款审计原始数据](../../归档/验收证据/第四轮_测试关节与任务书/spr1-and-contract-audit.json)。

## 手动复验顺序

1. 启动候选，等待 `Unity 就绪 · TCP 已连接`。在 1× 下播放，确认六路表格同屏、锁紧和分离事件、主时钟终止在 80.00 s。对照工作目录实测 [运行遥测](../../归档/验收证据/第四轮_测试关节与任务书/qt-ui/80秒候选原始遥测.jsonl)。
2. 暂停并打开敏感器页，分别选择 CRDS 与对接电视 A。检查 32°/55° 默认值。逐路保存数据及画面。对 CRDS 开始/停止逐帧录制，核对 PNG 和逐帧 JSONL 把序号、敏感器 ID 对上。见 [已保存目录](../../归档/验收证据/第四轮_测试关节与任务书/candidate/data/output/sensors)。
3. 跟随 [四状态验证](第四轮界面交互与回归.md) 检查关节角、太阳开关和锥面。读 [六路装配](敏感器位姿核对.md) 选择后续安装口径。
