# 空间位置关系计算模块

构建编号见同目录 `BUILD_VERSION.txt`。需要 64 位 Windows 和支持 Direct3D 11 的显卡。发布包包含 Qt 和 Unity 运行文件。

1. 双击 `SpatialPositionRelation.exe`，等待右上角显示「Unity 就绪 · TCP 已连接」。
2. 在 Unity 总览左上角勾选多路相机，画面沿右侧纵向排列。双击子视图铺满 Unity 区域，再次双击恢复。选「固定视角」保持预设构图，或选「可拖动视角」用左键环绕、中键平移、滚轮缩放。金色日盘和箭头标出太阳方向。
3. 在「位置/机构」选择具有可动太阳翼的参考模型并勾选「手动检查转轴」，选择目标、追踪或两器，再拖动滑块。取消勾选恢复自动对日。货运参考模型缺可动翼，控件会显示原因。
4. 默认关闭视场线。要观察线束，勾选「显示射线」并选择机位。对接演示结束后点「复位」返回演示起点。
5. 需要查看运行情况时点右上角「运行状态」→「查看中文运行记录」。诊断目录保留原始通信与模型标识。
6. 在「敏感器」页保存参数、遥测或相机单帧。「开始逐帧录制」保存 PNG 及对应遥测，再点一次结束。
7. 关闭 Qt 主窗口，应用会退出它启动的 Unity 子进程。

## 数据保存

默认写入程序目录下的 `data`。参数在 `data/config/user_config.json`，诊断日志在 `data/logs`，遥测和相机图片在 `data/output/sensors`。保存后 Qt 底部显示实际路径。

点击右上角「运行状态」查看当前路径并打开数据或诊断文件夹。点击「更改」可选一个可写的非 C 盘目录。当前参数保存到新目录，进行中的录制结束，Unity 重新连接以打开新日志。已保存文件仍在原目录。

路径优先级为 `--data-root "D:\试验数据\空间位置关系"`、程序目录中的 `config/data_root.txt`、默认的 `data`。取消启动时的数据目录选择会进入只读模式。

复制给其他电脑时，关闭软件后复制整个发布包。需要准备空白交付副本时，在副本中移走旧 `data` 和自定义 `config/data_root.txt`。
